How it works

Click the toolbar button on a website, then choose Translate. Only that tab is granted access. Code and equations are protected; the original content remains available. Reloading the page clears the translation.

Chrome internal pages, the Chrome Web Store, browser PDF views, shadow-root content, and inaccessible frames cannot be translated through this DOM workflow. For production, set Document app to http://127.0.0.1:8787.
