# Open Immersive Translator

Read websites and documents with the original text and translation side by side.

## Install with Codex

Copy and paste this into Codex. It will set up the environment and start the app for you:

```text
Install https://github.com/Syndr0/open-immersive-translator for me.
Reuse an existing checkout or clone it, and preserve my files and settings.
Read AGENTS.md if present, docs/setup.md and docs/agent-service.md.
Install the required environment and dependencies, build and start the app.
Reuse a working provider; otherwise use the free Google web translation option.
Verify a real translation and that documents and the extension share the backend.
Open the document reader and guide me through loading the Chrome extension.
Keep credentials on the backend. Ask before paid services or model downloads.
```

Once installed, choose a language and upload a document, or click **Translate** on a website.

The free Google option needs no API key or local model. It sends text to Google and uses an unofficial service whose availability can change.
